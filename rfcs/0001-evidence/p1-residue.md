## 3. The interpreter's implicit rules (de-facto interaction Defaults)

Written as the interpreter actually behaves; each is a candidate Defaults-table row, none needs vocabulary.

1. **Entry.** A persona's entry surface is the composed surface that lists the persona's first command's originating screen (EM `t: host /Auction catalog`); the player's entry is the bare form of the join command, reached through the `joinCode` field the host surface composes (`joinCode` → QR + URL). (R1, R62)
2. **Stream boundary navigation.** A command that opens or joins a stream navigates full-page to the stream's shell; every other command re-renders in place. (R2-R5)
3. **Surface selection.** `Select(state, viewer)` = phase → `during` cell; `viewer == hostPlayerId` → the `for: [Värd]` surface of that cell, else the `for: [Spelare]` one, else the unscoped one. Within a phase that has a per-player command: if the round's System-gear event has fired → the results surface; else if the viewer's issuing the command would fail an `Already…` guard → the waiting surface (the one composing the progress view derived from the Todo read-model); else the input surface. (R6-R8) — this is derivable, contradicting the xm comments that call it inexpressible; it never needed `when:`.
4. **Enablement.** A composed command is offered only when its state-only decider guards would pass (`NotEnoughPlayers` hides Start; `hasNext` picks Next vs End). The failing guard is explained in footer copy. (R14, R15)
5. **Manual pacing.** A System-triggered command composed on a persona's surface becomes that persona's button; the gear runs on POST. (R17)
6. **Gear timing.** Gears gated only by state run synchronously after any command that could satisfy them; time-gated gears also run on every poll. (R18, R19)
7. **Polling.** No typed-input command + non-terminal phase → poll every 1 s (comments and ADR say 2 s); input surfaces never poll and never auto-advance; terminal surfaces do not poll and gain play-again + share. (R13, R28, R29, R47)
8. **Feedback.** No confirmation, no undo, no optimistic state; the re-selected surface is the feedback, and the waiting surface's label is the confirmation copy. (R20, R21, R30, R31)
9. **Errors.** Bare-form command errors → global banner with `Describe(x)` copy; in-game command errors are silent (re-render); unknown stream → 404. (R23-R25)
10. **Identity marks.** `self:` → "du" tag / " · du" suffix; host row → "(värd)"; `winnerIds` → row highlight + banner. (R32-R34)
11. **Presence.** The materializer may fold a listed field into another field's copy or the heading and drop it from the bag; the heading is the surface label if present, else a chosen data field, else absent. (R36, R37)
